# dBASE Plus - Forms and tables for a desktop database you keep

Screens and tables should live in one named dBASE app you keep. Loose DBF copies wait off the live set.

## Session Card

| Slice | What you do in dBASE Plus | What remains |
|-------|---------------------------|--------------|
| Arrival | Open dBASE Plus on the desktop database you keep and name the app desk | A titled dBASE app |
| Focus | Keep data forms and one table app in front | A short screen list |
| Check | Read the form before you change tables you own | A confirmed desktop database |
| Handoff | Leave the dBASE Plus app desk on that local dBASE | A note for the next visit |

## How dBASE Plus Sits

dBASE Plus does not replace the DBF files you already keep. It sits beside them as named data forms and table apps for a dBASE Plus desktop database you keep.

If two people share a PC, each keeps a dBASE Plus app desk of their own. Extra screens wait for their own title instead of crowding the live forms.

A first visit should be one short form, then the same dBASE Plus table apps the next day. That is enough to see if the layout holds on a database you own.

## Traffic Light

| Signal | On the dBASE Plus app desk | What you do |
|--------|----------------------------|-------------|
| Green | Named dBASE app, forms on your tables | Continue the same app desk |
| Amber | Forms from two databases mixed | Split the set before a large change |
| Red | No title, loose DBF copies everywhere | Stop and name the dBASE app first |
| Clear | Handoff written, screens few | Close dBASE Plus and leave the desk |

## Open Order

1. Open the last dBASE Plus session on a desktop database you keep, not a new empty app.
2. Read the data forms, the table apps, and the last handoff.
3. Finish one visible screen inside dBASE Plus data forms.
4. Write what changed on your own tables, then close with fewer loose DBF copies than you found.
5. If the app desk feels crowded, drop anything that belongs to a different dBASE job.
6. Leave table apps on the same named dBASE Plus desktop database.
7. Close with the form desk quieter than the session you opened.

## After a Week

A week in dBASE Plus is not more open screens. It is the same data forms, a shorter table app list, and a note that still makes sense on Monday. If every form is live, nothing stands out.

Take finished screens off the live set so the next visit starts on the dBASE Plus desktop database that is still open.

Other programs stay where they are. dBASE Plus only keeps the path back: app name, forms, tables, handoff.
Leave the app desk quieter than the forms you opened.

## Sign-off

- [ ] The dBASE Plus app name is short enough to scan
- [ ] Only the desktop database you keep is on the app desk
- [ ] A second person can read the last form note
- [ ] The last dBASE Plus session still opens after a restart
- [ ] Finished screens are off the live form desk
- [ ] Table apps still match dBASE Plus data forms
- [ ] The app handoff still names the owned database

## Field Note

dBASE Plus is easier to trust when the app desk stays smaller than the folder of loose DBF copies around it. Name the app, keep data forms on tables you own, finish one visible screen, and write what changed.

The same loop fits a shop file, a clerk packet, or a shared computer. Open the last dBASE Plus session and continue. Do not rebuild the forms from scratch.
